## 📖 工作流详情

### 1. 城市文旅视频

- **输入**：一个城市名称。
- **输出**：三段拼接好的 3D 唯美风格城市宣传视频。
- **流程**：调用大模型生成 3 张城市特色图片提示词（国内城市含 3D 中文名、国外城市含 3D 英文名）→ 转化为图生视频提示词（每张图一个丝滑转场）→ 批量文生图 → 批量图生视频 → `concat_videos` 拼接输出。

### 2. 最新版微观世界小人国

- **输入**：一个生活日常主题。
- **输出**：微观小人国风格的精美图片 / 拼接短视频。
- **流程**：场景构造（大模型）→ 文生图 / 图像生成 → 图生视频 → 循环与选择器控制多场景 → 变量聚合、图片保存（`save_list` / `get_table`）→ 视频拼接。
- 相比其他两套，本工作流节点更多、支持循环批量生成多场景。

### 3. 欧美3D卡通视频

- **输入**：一个角色设定。
- **输出**：带配音的欧美 3D 卡通短视频。
- **流程**：以角色第一人称生成育儿文案 → 生图 prompt → 图像生成 → 图生视频提示词 → 视频生成 → 语音合成（`speech_synthesis`）→ 音画时长对齐与合成（`get_audio_duration` / `compile_video_audio` / `concat_videos`）。

## 🚀 使用方式

### 方式一：一键导入（推荐）

1. 打开对应文件夹中的 `.zip` 压缩包，解压得到工作流文件。
2. 登录 [coze.cn](https://www.coze.cn/space)，进入「工作空间 - 资源库」。
3. 点击右上角「导入」，选择解压后的文件上传，等待导入完成即可。

### 方式二：手工复制

部分账号不支持一键导入时，可用此方式：

1. 登录 [coze.cn](https://www.coze.cn/)，进入「工作空间 - 资源库」新建一个工作流并打开（此时只有「开始」「结束」两个节点）。
2. 打开对应文件夹中的 `.txt` 文件，全选复制，粘贴到工作区，所有流程节点会自动生成。
3. 粘贴的内容不含「开始」「结束」节点，需手工把原有的开始、结束节点与粘贴的流程连接，并按提示创建或关联输入项、输出项（**注意名称和类型要保持一致**）。

> 详细图文步骤请参考仓库内 `coze工作流源码使用说明.docx`。
